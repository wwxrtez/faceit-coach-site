FACEIT Coach

Privacy Notice

Last updated: 26 October 2026

This notice describes the intended handling of information in the FACEIT Coach desktop prototype. Update this notice if the product's data flows change before public release.

Information the app may process

When you search for a public FACEIT profile, the app may process the nickname or profile link you entered and public profile/statistics returned by the configured data provider, such as FACEIT player identifiers, avatar, game rating, match results and available performance statistics.

Local storage

The desktop prototype stores its profile selection, settings, training goals and progress data in a local application database on the user's device. Voice notes, when enabled, may be stored in the app's local data directory. The user can remove local data using the app's reset controls or by uninstalling and deleting its data folder.

Passwords and authentication

FACEIT Coach should not ask users to enter their FACEIT password, Steam password, authenticator code, recovery code or QR-based two-factor authentication secret. Never share these secrets with the app developer.

Third-party services

Profile searches that use FACEIT's official data service send the search query to that service. FACEIT handles those requests under its own policies and terms. If a future version uses a hosted Coach server, this notice must be updated to identify that service, the data sent to it, retention periods and the applicable contact details before that version is released publicly.

Retention and deletion

In the desktop prototype, locally stored information remains on the device until the user deletes it through app controls or removes the local app data. This statement does not apply to data retained by third-party services under their own policies.

Children and contact

FACEIT Coach is a gaming statistics companion, not an account-recovery or authentication service. Before public release, the project owner must provide a working support contact and review this notice against the final app implementation and applicable law.

Project owner action required before submission: publish with a valid support contact, verify that the described storage matches the actual build, and update this notice if the app sends queries or identifiers to any server other than FACEIT.
