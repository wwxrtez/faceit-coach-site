Privacy Notice

This notice explains what the FACEIT Coach project website does and how the desktop prototype is intended to handle player-related data.

Last updated: 26 October 2026
Development-stage notice. FACEIT Coach is a prototype in active development. Network behavior and locally stored data can vary by build; this notice must be kept aligned with the specific version distributed to users.

1. The project website

This is a static project website hosted by GitHub Pages. The pages do not provide a player-search form, collect FACEIT or Steam passwords, or include analytics or advertising scripts. GitHub may process technical request logs as part of hosting the website under its own policies.

2. Information the desktop app may process

Depending on the build and enabled features, the desktop app may process information that a user enters to identify a public profile, such as a FACEIT nickname or profile link, and public profile data returned by the configured data source. This can include a player identifier, avatar, CS2 rating, match results and available performance statistics.

The app should not require the user to provide their FACEIT password, Steam password, authenticator code, recovery code, or two-factor authentication QR secret.

3. Local application data

Builds with profile and planning features may save a selected profile, preferences, training goals, progress snapshots and other app settings in a local database on the user's device. If voice-note features are enabled, audio may be saved in the application's local data directory. Exact storage depends on the build being used.

Users should use the reset controls provided by their build to remove saved app data. Uninstalling alone may not always delete application data stored separately by the operating system.

4. Profile searches and third-party services

When live profile lookup is enabled, the entered nickname, profile URL or identifier may be sent to FACEIT's data service or to a configured service that relays requests to the data provider. The specific destination depends on the build. FACEIT and any other service involved process requests under their own terms and privacy notices.

This website itself does not perform FACEIT searches or return live player statistics.

5. Retention and deletion

Data saved locally by the desktop app generally remains on the device until it is removed using app controls or the relevant local application data is deleted. Third-party services may process or retain requests according to their own policies and technical requirements.

6. Security and account credentials

Do not send passwords, 2FA codes, recovery codes, API credentials or QR-based authenticator secrets through the app's support channels. Developer credentials must not be embedded in public source repositories or distributed client code.

7. Contact

For questions about this project or this notice, contact the project maintainer through the FACEIT Coach GitHub repository issues page. Do not include passwords, authentication codes or private account information in public issues.
